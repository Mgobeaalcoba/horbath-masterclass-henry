# Ejemplo de solicitud válida

**Asunto:** Actualizar acceso de Juan Pérez al proyecto Cliente X

**Cuerpo:**

Hola, necesitamos gestionar el acceso de Juan Pérez al proyecto Cliente X. Su email es juan.perez@example.com y necesita el rol de colaborador. Idealmente debería quedar resuelto antes del viernes. Por favor, confirmen cuando esté registrado.

## Resultado esperado

- Categoría: `Accesos`.
- Prioridad: `Media` o `Alta`, según la fecha vigente de la demo.
- Persona objetivo: Juan Pérez.
- Proyecto/cliente: Cliente X.
- Solicitud de aprobación humana: `true`.
- `validation_passed`: `true`, si la fecha se puede resolver sin ambigüedad y no faltan datos requeridos.
- Acción: registrar, derivar y notificar; no ejecutar el cambio de acceso.
