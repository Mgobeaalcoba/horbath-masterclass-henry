# Ejemplo de solicitud incompleta

**Asunto:** Necesitamos dar acceso a Juan

**Cuerpo:**

Hola, necesitamos que Juan tenga acceso al proyecto del cliente. ¿Lo pueden gestionar?

## Resultado esperado

- Categoría probable: `Accesos`.
- Información faltante: email de Juan, proyecto/cliente, sistema o permiso requerido y fecha objetivo.
- `validation_passed`: `false`.
- Acción: pedir información faltante y registrar en `Solicitudes_Incompletas`.
