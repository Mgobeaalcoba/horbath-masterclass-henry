# Deck editable

Esta carpeta está preparada para recibir el PPTX editable de la masterclass.

Subir el archivo a `deck/assets/` con un nombre estable, por ejemplo:

```text
deck/assets/intelligent-request-automation-masterclass-horbath.pptx
```

El PDF de referencia se conserva en `docs/sources/`. Las notas narrativas y las transiciones están en `docs/07-deck-notes.md`.
